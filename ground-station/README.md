# Ground Station

Software de estación terrena responsable de recibir, visualizar y gestionar la información intercambiada con el CanSat.

Este directorio alojará el código fuente, recursos, configuración y pruebas del subsistema. Las decisiones de plataforma, interfaz y dependencias están pendientes de definición.

La comunicación con Flight Software debe respetar el contrato definido en [`../protocol/`](../protocol/).
