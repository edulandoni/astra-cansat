# DEPRECATED — archivo de simuladores históricos

Conservo estos trabajos para reconstruir cómo llegué al banco actual. DEPRECATED significa que ya no los tomo como base operativa vigente; no significa que estén borrados ni que todos sus resultados sean inválidos.

| Antecedente | Para qué lo hice | Alcance que conservo |
| --- | --- | --- |
| [Estación v04](estacion-v04/README.md) | Explorar recepción simulada, pantalla, fallas y ayudas | Código original de Drive; sin USB ni RF reales, referencias v1. |
| [Laboratorio v05](laboratorio-v05/README.md) | Aprender y comprobar cálculos con datos inventados | Altura, pendiente, potencia y energía; no es receptor de vuelo. |

No mezclo su numeración con banco-usb-v0.1: pertenecen a líneas de prototipo distintas. Los vínculos históricos a presupuesto u otros materiales no amplían el alcance de esta carga. Conservo los originales externos en Drive y el [PR de antecedentes](https://github.com/edulandoni/astra-cansat/pull/1).

Las fuentes históricas permanecen intactas, incluidas sus afirmaciones antiguas. Las advertencias actuales están en estos README separados. El respaldo de archivos y sus huellas está en [manifest de importación](../../docs/importacion-fuentes-2026-10-19.json).

Relaciono el trabajo con [ASTRA-20](https://astrateam2026.atlassian.net/browse/ASTRA-20), [ASTRA-21](https://astrateam2026.atlassian.net/browse/ASTRA-21) y [ASTRA-22](https://astrateam2026.atlassian.net/browse/ASTRA-22).
