# Flight Software

Software embarcado responsable de ejecutar las funciones de vuelo del CanSat.

Este directorio alojará el código fuente, interfaces, bibliotecas internas, configuración y pruebas del subsistema. Las decisiones de plataforma, arquitectura y dependencias están pendientes de definición.

La comunicación con Ground Station debe respetar el contrato definido en [`../protocol/`](../protocol/).
